The examples are organized by interface:

- [Python](/examples/python/) — rendered HTML, sessions, cookies, JSON, screenshots, and personas.
- [Node.js](/examples/node/) — page lifecycle, structured evaluation, screenshots, and cancellation.
- [CLI and CDP](/examples/cli-and-cdp/) — shell automation and Puppeteer connectivity.

Choose one native binding for new application code. Use CDP when integrating an
existing supported Puppeteer workflow, and use the CLI for small shell-oriented
jobs.
