Brimp combines JavaScriptCore, Blitz DOM/layout, and curl-impersonate into a
headless browser worker.

- **CLI** for extraction, crawling, JavaScript evaluation, and screenshots.
- **CDP** for supported Playwright and raw-protocol automation.

Start with the [quick start](/quick-start/) or read the
[development guide](/development/).
