Brimp combines JavaScriptCore, Lexbor, and curl-impersonate behind Python and Node
Session/Page APIs. Fetch pages, execute their scripts, and work with a live DOM.
DOM operations, networking, Web Streams, and WebCrypto are core capabilities.
Optional JavaScript plugins supply storage, extraction, and specialized APIs.

Start with the [quick start](/quick-start/) and [API overview](/api/).
