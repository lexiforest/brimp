Brimp lets agents and scripts work with pages that depend on JavaScript.
Use it when an HTTP response contains an HTML shell and JavaScript supplies
the content you need. Fetch the page, let its scripts update the document, then
read the HTML, evaluate JavaScript, or extract an article as Markdown.

Brimp runs inside your Python or Node.js application and also provides a CLI.
It executes page scripts without opening a browser window. Tasks that need
layout, screenshots, or visual interaction require a full browser.

Install the [Python or Node.js package](/install/), then run the
[quick start](/quick-start/).

## Pick an interface

- **Python** for synchronous, Requests-style navigation and extraction.
- **Node.js** for an asynchronous in-process browser API.
- **CLI** for shell scripts, JavaScript evaluation, and page extraction.
