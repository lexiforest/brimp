Install a Python or Node.js package for your application, or the standalone CLI.
All three include the native runtime; no Rust toolchain or separate SDK download
is needed.

| Platform | Minimum system |
| --- | --- |
| macOS Apple silicon | macOS 11 |
| Linux x86_64 or arm64 | glibc 2.34 |
| Windows x64 | The package includes the required Visual C++ runtime DLLs |

Intel macOS and Windows arm64 packages are not provided.

## Python

Use Python 3.11 or newer. Create a virtual environment, activate it, and install
Brimp from PyPI:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install brimp
```

On Windows PowerShell, create the environment with `python -m venv .venv`, then
run `.venv\Scripts\Activate.ps1` before the install command.

## Node.js

Use Node.js 22.19 or newer. In your application's directory:

```sh
npm install @brimp/brimp
```

If you are starting a new project, run `npm init -y` first. Save examples as
`.mjs` files so Node.js treats them as ES modules.

## CLI

On Linux x64/ARM64 or macOS Apple silicon:

```sh
curl -fsSL https://brimp.ai/install.sh | sh
```

The installer verifies the release checksum and installs `brimp` in
`$HOME/.local/bin`. If that directory is outside your `PATH`, it prints the line
to add to your shell profile. Check the installation with `brimp doctor`.

To choose a version or install directory:

```sh
curl -fsSL https://brimp.ai/install.sh | sh -s -- --version v0.1.2 --prefix "$HOME/.local"
```

On Windows x64, download the CLI ZIP from [GitHub Releases](https://github.com/lexiforest/brimp/releases/latest).
Extract it and run `.\brimp.exe doctor` in PowerShell. Keep the executable and
its DLLs together; add that directory to your `PATH` to use it from other folders.

## Verify the runtime

Python:

```python
import brimp

with brimp.Session() as session:
    page = session.new_page()
    print(page.evaluate("typeof document.querySelector"))
```

Node.js, saved as `verify.mjs` and run with `node verify.mjs`:

```js
import { createSession } from '@brimp/brimp';

const session = await createSession();
try {
  const page = await session.newPage();
  console.log(await page.evaluate('typeof document.querySelector'));
} finally {
  await session.close();
}
```

Both print `function`. Continue to the [quick start](/quick-start/) to fetch a
page and read the document after its JavaScript runs.

## Build or customize Brimp

To change the runtime or compile it yourself, follow [Build from source](/development/build-from-source/).
Package users do not need those steps.
