---
title: Install
---

Native package builds require matching JavaScriptCore and curl-impersonate SDKs.
Set `BRIMP_JSC_LIB_DIR` and `BRIMP_CURL_LIB_DIR` to their library directories.
Lexbor is pinned and vendored in the repository.
WebCrypto builds OpenSSL from Cargo-pinned source; source builds require a C
compiler, make and Perl, with no OpenSSL shared library needed at runtime.
On macOS, set `DYLD_FRAMEWORK_PATH` to the JSC framework directory at runtime
when using a WebKit SDK that retains the system framework install name.

```sh
cargo build -p brimp-python -p brimp-node
python3 bindings/prepare_local.py
maturin build --manifest-path bindings/python/Cargo.toml
npm pack ./bindings/node
```

The wheel/npm package includes the native extension and bundled plugin sources.
Install JSC/curl on the target machine; these are SDK-linked packages, not a
self-contained browser distribution. On macOS, `python3 bindings/package_native.py`
assembles relocatable archives with JSC/curl and their notices. Source builds are documented in
[Development](/development/).
