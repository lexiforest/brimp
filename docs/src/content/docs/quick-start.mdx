```python
from brimp import Session
from brimp.plugins import extraction

with Session(plugins=[extraction()]) as session:
    page = session.get("https://example.com")
    print(page.status_code, page.url)
    with page.query_selector("h1") as heading:
        heading.set_text_content("Updated")
        print(heading.text_content())
    print(page.extract()["contentMarkdown"])
```

```javascript
import { createSession, extractionPlugin } from 'brimp';
const session = await createSession({plugins: [extractionPlugin()]});
try {
  const page = await session.get('https://example.com');
  console.log(await page.evaluate('document.title'));
  console.log((await page.extract()).contentMarkdown);
} finally { await session.close(); }
```

Plugins are explicit; a default session does not install storage, Canvas,
services, or extraction. Detached elements retain identity. Navigation invalidates
handles from the previous realm. Python timeouts use seconds; Node uses milliseconds.
See [API](/api/) for events, routes, input, and streaming bodies.
